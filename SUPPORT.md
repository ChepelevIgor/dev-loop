# Dev Loop support

Начни со [справки Dev Loop](skills/help/references/guide.md): она объясняет навыки, настройку, кнопки и типичные причины остановки. В чате можно выбрать навык `help` и задать вопрос обычными словами.

Publisher: Igor Chepelev — https://github.com/ChepelevIgor

For bug reports, installation problems and questions, [open an issue](https://github.com/ChepelevIgor/dev-loop/issues/new) or [browse existing issues](https://github.com/ChepelevIgor/dev-loop/issues). This is the public support channel for Dev Loop.

Repository: https://github.com/ChepelevIgor/dev-loop

Privacy notice: https://github.com/ChepelevIgor/dev-loop/blob/main/PRIVACY.md

For diagnosis, record the plugin version, operating system, selected workflow, expected behavior, actual behavior, and the failed command's exit code. Include only a small redacted excerpt of the relevant error. Do not attach `.devloop/` wholesale: it may contain code, app data, screenshots, PR comments and local access tokens. Never include credentials.

If no simulator is available, configure and boot the intended device before resuming verification. If GitHub access fails, fix the normal local GitHub CLI login or repository access. Do not convert those failures into an empty review. If the queue is blocked, inspect the failure and any external effects before using the documented recovery commands.
