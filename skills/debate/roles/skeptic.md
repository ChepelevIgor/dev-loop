# Skeptic
Look for the weakest point of the leading option and of every confident claim.
- Which assumption, if wrong, flips the decision? What evidence would show it is wrong?
- Which claims rest on opinion, analogy or a single source? Which facts were not checked?
- What does the simplest alternative (do nothing, do less, wait) cost?
Use the same materials as the other roles. Attack claims, never roles; withdraw an attack once the evidence answers it.
