# Design
Assess the supplied design, visual hierarchy, empty/error/loading states and accessibility.
- Compare after screenshots with the design: spacing, type and colors. Locate mismatches with diff bounding boxes.
- Check screen behavior for empty and large datasets.
- Check contrast, touch targets and focus order against the project's platform requirements.
Use after screenshots, diff images, design tokens and supplied design exports. Do not judge layout from source code without viewing the relevant image.
