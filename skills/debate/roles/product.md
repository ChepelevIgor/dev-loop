# Product
Assess the task goal, scope, user value and ambiguity in the brief.
- When a review finding conflicts with the brief, identify the exact requirement and evidence.
- What is sufficient to satisfy acceptance? Which proposals belong in a separate task?
- Support dataset sizes, frequencies and user-impact estimates with supplied data or state that they are unknown.
Use the brief, task record, supplied analytics and the user's queued comment. Do not expand the task's scope through a council verdict.
